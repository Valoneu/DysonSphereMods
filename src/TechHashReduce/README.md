# TechHashReduce
**Research Cost Optimization**

---

![Category](https://img.shields.io/badge/Category-Tweak-blue?style=flat-square)
![Warning](https://img.shields.io/badge/Warning-Stability-red?style=flat-square)

Provides granular control over technology research requirements by scaling the "hashes" needed for upgrades and unlocks.

---

## Features
* **Dynamic Scaling:** Multiplies the required hash cost for every technology.
* **Granular Range:** Supports multipliers ranging from **0.01x** to **100x**.
* **Full Integration:** Applies to both the standard technology tree and infinite upgrades.
