# VesselTrails

Activates high-performance rendering for beautiful, dynamic logistics vessel travel trails inside the Star Map. Gives you a live, visual heartbeat of your entire galactic logistics web moving between stars.

---

## Technical Information

### Mechanics and Configuration
- Configurable toggles for trail rendering limits, segment length, and alpha fade timing.

### Deep Technical Details
Intersects standard UI rendering pools, safely pushing visual vertex elements directly into the 3D Star Map canvas layer using the game's ultra-fast native object pooling methods.

### Dependencies
* **BepInEx**
