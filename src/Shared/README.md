# DysonSphereMods.Shared
**Common Utility Library for Valoneu's Mods**

---

This is a shared project used by multiple mods in this repository to provide consistent logging and utility functions. It ensures all mods have a unified experience and simplifies development by centralizing common tasks.

---

## Features

### Logging Utility
* **Shared Logger:** Provides a wrapper around BepInEx's `ManualLogSource` to ensure consistent formatting across all mods.
* **LogOnce:** A specialized function for reporting messages only once per session to avoid console spam during development.
