# FactoryOverclock

Global throughput and speed multiplier for your entire factory. Scales production speeds for Assemblers, Smelters, Miners, Labs, and even Silos/Ejectors while dynamically scaling power requirements to balanced levels.

---

## Technical Information

### Mechanics and Configuration
- `Hotkey`: `KeypadMinus` to toggle overclocking.
- Independent multipliers for all machine types (Assemblers, Belts, Sorters, Silos, etc.).

### Deep Technical Details
Uses Harmony transpilers to double-tick logistics (splitters/pilers) and pre-calculates component work-energy logic to ensure high performance even at 20x speed.

### Dependencies
* **BepInEx, CommonAPI**
