# SortByStorage
**Advanced Statistics Sorting for Dyson Sphere Program**

---

![Category](https://img.shields.io/badge/Category-UI-blue?style=flat-square)
![Utility](https://img.shields.io/badge/Utility-Information-green?style=flat-square)

SortByStorage adds a highly requested sorting method to the Production Statistics panel. It allows you to sort items based on their current stored quantity across the selected filter (Global, Star, or Planet).

---

## Key Features

### Storage-Based Sorting
* **New Sort Option:** Adds a "Storage" entry to the sorting dropdown in the Production tab.
* **Descending Order:** Items with the highest total storage (chests, tanks, belts, and stations) are moved to the top.
* **Real-time Accuracy:** Forces a refresh of storage counts when the statistics panel is opened to ensure you see the most accurate data.

### Seamless Integration
* **Native Look & Feel:** The sorting option integrates directly into the existing game UI.
* **Performance Focused:** Uses high-performance sorting algorithms and targeted patches to ensure no impact on UPS/FPS.
